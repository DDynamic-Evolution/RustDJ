# RustDJ brand assets

The approved violet record / negative-space R / lavender waveform identity is embedded in the application header and native window. Windows MSVC builds also embed the multi-resolution executable icon and version information using the Windows SDK resource compiler.

- `rustdj-logo.png`: horizontal logo on a dark background.
- `rustdj-icon.png`: original app icon with transparent corners.
- `rustdj-window-icon.png`: 256 px window icon, derived from the original PNG.
- `rustdj.ico`: Windows icon with 16, 20, 24, 32, 40, 48, 64, 128 and 256 px images.
- Run `powershell -File scripts/prepare-branding.ps1` from the repository to regenerate the ICO from the approved PNG. This only converts sizes/formats; it does not redesign the mark.

The PNG artwork was created using the built-in ImageGen tool, then approved for integration. The ICO is a size/format conversion of that artwork. No image generation service is called by RustDJ.

## Original icon prompt

Use case: logo-brand. Asset type: first design draft for the Windows app icon of RustDJ, a four-deck DJ mixing application. Create one original, minimal, very legible square app icon, centered and occupying most of the canvas. A charcoal (#121315) rounded-square tile with generous round corners; within it, a bold geometric purple (#AE77FF) vinyl-record ring cleverly fused with an unmistakable capital R in negative space. The diagonal leg of the R ends in a short simple audio-wave gesture in light lavender (#DBBAFF). Make the vinyl/R fusion coherent, elegant and instantly readable, with thick shapes and large negative spaces so it also works at 24 pixels. Restrained two-tone purple palette. Flat, crisp, vector-like graphic design, no 3D, no metallic surfaces, no texture, no photographic turntables, no tiny concentric grooves, no neon glow, no cast shadow, no slogans, no other lettering, no existing brand logos. Keep everything within the icon silhouette, transparent pixels outside the rounded tile. Genuine transparent background, not a checkerboard illustration. This is only a design draft; do not show packaging or a mockup.
